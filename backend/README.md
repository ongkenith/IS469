# INFORMATION OF APPLICATION BACKEND
This is a Flask application to call the API from model_server application

## Getting Started

Ensure that you have followed the instructions to download the Python dependencies (refer to README in root folder).

To run the Flask server:

```bash
cd backend  # If you are still in your root directory
python main.py
```

Your application should be running on http://127.0.0.1:5000/

Any edits will force the application to auto-reload.
