# INFORMATION OF APPLICATION FRONTEND
This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

To run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Any edits will auto-updates on the page as you edit the file.

NOTE: This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

### AI Content
The UI code is generated by AI *at the start*. The prompt used is as follows:
```text
Create a simple messaging chat like those in a game. The code should be usable for Next.js application, with Typescript.

Requirements:
- Before one start chatting, there will be a start button to press to begin typing the chat
- After finished chatting, the user can press a button to end the chat. The chat history should be stored somewhere to be sent to an API later
- The design of the messaging chat should be simple colors. Black and white is fine too
- If required, tell me which code to be placed in which file. Else, combine all into one tsx file (only if code length is not too long to maintain)
```
