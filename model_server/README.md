# INFORMATION OF APPLICATION BACKEND
This is a Flask application to run the model

## Getting Started

Ensure that you have followed the instructions to download the Python dependencies (refer to README in root folder).

To run the Flask server:

```bash
cd model_server  # If you are still in your root directory
python model_server.py
```

Your application should be running on http://127.0.0.1:5001/

Any edits will NOT force the application to auto-reload. Please manually restart the process (in terminal) to update the changes
